📖 Cara Bermain

🎮 Kontrol Dasar
🖱️
Gerak Mouse / Sentuh Layar Kepala naga mengikuti posisi kursor atau jarimu secara real-time
🖱️🔥
Tahan Klik Kiri / Tahan Sentuh Tembakkan Bola Api ke arah musuh — aktif setelah skor ≥ 30
🛡️
Klik Kanan Perisai Aktifkan Perisai Naga selama 2 detik — memblokir proyektil & tabrakan musuh. Cooldown 12 detik. Aktif di skor ≥ 30
⏸️
Spasi atau tombol P Pause / Lanjutkan permainan kapan saja selama bermain
❤️ Sistem Nyawa
❤️❤️❤️
Naga Memiliki 3 Nyawa Kena musuh atau proyektil tidak langsung Game Over — hanya mengurangi 1 nyawa. Baru Game Over saat semua 3 nyawa habis!
💫
Invincibility — 2.5 Detik Kebal Setelah kena damage, naga berkedip merah dan menjadi kebal selama 2.5 detik. Manfaatkan waktu ini untuk makan atau menjauh dari musuh!
📊
Indikator Nyawa di Papan Skor Sisa nyawa ditampilkan sebagai ikon hati di bawah skor: ❤️ = hidup, 🖤 = hilang. Pantau terus agar tidak kehabisan!
✨ Item & Power-Up
💎
Kristal Energi +1 Poin Makanan utama yang selalu ada di lapangan. Makan sebanyak mungkin untuk tumbuh dan berevolusi!
⭐
Relik Matahari +5 Poin Item langka berwarna kuning emas. Muncul 15% peluang mulai skor 18, dan pasti muncul di skor 20. Memberikan Mode Lincah selama 5 detik!
❄️
Serpihan Es Power-Up Beku Muncul 15% peluang per makan mulai skor 10. Membekukan musuh selama 5 detik — gunakan kesempatan ini untuk makan sebanyak mungkin!
💀 Musuh — Tengkorak Api
💀
Muncul di Skor 10 Bergerak memantul di seluruh layar. Menyentuhnya akan mengurangi 1 nyawa dan memberimu 2.5 detik kebal — kena 3 kali berarti Game Over!
⚡
Makin Cepat Setiap Makan Kecepatan musuh bertambah 7% setiap kali kamu makan. Di skor tinggi, musuh bisa bergerak sangat agresif!
🔥
Serang dengan Bola Api (skor ≥ 30) Tembak musuh dengan bola api untuk melumpuhkannya 2 detik dan mendorongnya menjauh (Knockback). Musuh terbakar berwarna oranye.
📏
Musuh Membesar Seiring Waktu Radius bahaya musuh ikut membesar saat berevolusi — di fase Iblis Infernal (skor 30+), ukurannya 2× lipat dari awal!
⚔️ Kemampuan Lanjutan — Skor 30+
💨
Jurus Musuh 1 — Dash Attack Skor 30+ Musuh mengunci posisimu lalu melesat sangat cepat selama 0.8 detik. Perhatikan ring merah berkedip + teks "DASH!" — itu peringatan 1 detik sebelum serangan!
💀
Jurus Musuh 2 — Proyektil Tengkorak Skor 40+ Musuh menembak bola api merah yang membidik tepat ke arah kepalamu setiap ~6 detik. Makin tinggi skor, makin cepat dan makin sering!
🌀
Jurus Musuh 3 — Teleport Skor 50+ Musuh berkedip ungu sebagai peringatan lalu berpindah tiba-tiba ke posisi acak yang jauh darimu. Jangan lengah!
🛡️
Kemampuan Naga — Perisai Klik Kanan Aktifkan perisai biru bercahaya selama 2 detik. Memblokir proyektil & mencegah game over dari tabrakan musuh. Cooldown 12 detik. Gunakan saat melihat peringatan Dash!
